# Daily Reflection — Version 1

A very simple phone-friendly daily reflection app.

## What it does

- Three repeating daily questions:
  1. Do you have a plan for tomorrow? (health, fitness, project – or hours? – or location?)
  2. Is there something you are looking forward to?
  3. Do you know what you are going to eat?
- Automatically saves answers on the device.
- Move backward and forward by day.
- Separate "Must Do" and "Want To Do" lists.
- Check off tasks or delete them.
- Works offline after the app has been opened once.

## Put it on an iPhone

The easiest route is to host these four files on a simple HTTPS website (for example, GitHub Pages), open the site in Safari on the iPhone, then use:

Share → Add to Home Screen

No Mac is required.

## Important

This version stores everything in the browser's local storage on that device. Clearing Safari website data can erase the entries. It does not sync between devices.
